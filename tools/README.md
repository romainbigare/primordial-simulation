# Check scripts and probes of the work on the map, the ground, the climate and the speed

Study files, kept on this branch only (never on main). Each was written for one measurement; paths inside them point
at a scratch folder and at ports of that day: read a script before you run it.

- `check/`: `paused.js` (load the page, play, pause, shoot the fitted map and a zoomed place), `phone.js` (the same on
  a phone profile), `inspect.js` (click a place and print what the page says about it).
- `frame/`: the bench of the frame's cost (`bench.js`, the build and knock-out scripts, the work counts, the pixel
  differences).
- `speed/`, `page/`: the core's speed runs and the page's pace and date lag.
- `climate/`: the per-row tables and maps of a banded island; `climate/probes/`: the probes that write them.
- `shape/`, `shapetool/`: the ground's variety tables (heights, slopes, relief, coast) and the islands' sheets.
- `crisp/`, `plants/`: the shoot and compare scripts of the drawing packages.
